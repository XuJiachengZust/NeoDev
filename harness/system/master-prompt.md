# 仓库级总提示

- 当前工作区是单项目后端仓库；先识别实际命中的代码域，再进入对应规则。
- 根级 `harness/` 只放当前仓库稳定可复用的协作规则，不要引入与现状无关的多项目约束。
- `harness` 按渐进式加载使用：先最小必要规则，再按业务、开发、环境和子项目继续补读。
- 当前核心代码域是 `src/service/`、`src/deepagents/`、`src/gitnexus_parser/`，部署与运行配置在根目录和 `docker/`。
- 发生代码变更后，应及时清理本次变更已替代的旧代码、废弃代码和失效配套描述；无明确兼容依据时，不保留双轨实现。
- 修改完成后，判断是否需要把稳定经验沉淀到 `harness/`。
