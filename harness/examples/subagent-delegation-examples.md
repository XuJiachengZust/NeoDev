# 标准分派示例

## 创建参数示例

```text
执行器子智能体创建参数示例：
- agent_type: worker
- model: gpt-5.4-mini
- reasoning_effort: medium
- fork_context: false

说明：`worker` 对应执行器、`explorer` 对应评估器，这只是推荐映射，不代表平台层面的权限隔离。

评估器子智能体创建参数示例：
- agent_type: explorer
- model: gpt-5.4-mini
- reasoning_effort: medium
- fork_context: false

若评估任务只需要局部上下文，不要为了省事改成 fork_context: true。
若希望评估器尽量只读，仍需在任务文本里额外写明禁止修改文件、禁止执行会写入状态的操作。
```

## 执行器子智能体分派示例

```text
你当前是执行器子智能体。

创建参数：
- agent_type: worker
- model: gpt-5.4-mini
- reasoning_effort: medium
- fork_context: false

任务目标：
修复用户登录失败时的空响应处理问题。

上下文范围：
仅查看登录接口相关代码、接口封装和与本问题直接相关的 harness 规则。

修改边界：
只允许修改登录流程相关文件，不得扩展到其他认证逻辑。

禁止事项：
1. 不得重定义任务目标。
2. 不得顺手修复无关问题。
3. 不得替主智能体做最终收口判断。

预期产出：
1. 完成必要代码修改。
2. 返回修改摘要。
3. 返回验证结果和遗留风险。

验证标准：
登录空响应场景可被正确处理，且修改未越出允许边界。
```

## 评估器子智能体分派示例

```text
你当前是评估器子智能体。

创建参数：
- agent_type: explorer
- model: gpt-5.4-mini
- reasoning_effort: medium
- fork_context: false

任务目标：
检查登录空响应处理修复是否达标。

上下文范围：
仅查看本次修改涉及的文件、验证说明和相关规则。

检查边界：
只评估是否满足目标、是否越界、是否存在明显回归风险。

禁止事项：
1. 不得继续扩展实现。
2. 不得替主智能体决定新任务。
3. 不得把建议直接升级为新的主线任务。
4. 不得修改文件，不得执行会写入状态的命令或操作。

预期产出：
1. 给出通过 / 不通过 / 有风险待修复的结论。
2. 说明发现的问题和风险。
3. 给出是否需要继续修复的建议。

验证标准：
结论可复查，且明确对应任务目标与边界。

补充说明：
这里的只读要求来自任务约束，不代表平台对 `explorer` 提供了硬性只读权限。
```

## 角色不清时的澄清示例

```text
当前角色不清，无法继续。

请先明确：
1. 我当前是执行器子智能体还是评估器子智能体。
2. 创建时使用的 `agent_type`、`model`、`reasoning_effort`、`fork_context` 是什么。
3. 本次允许修改或检查的边界是什么。
4. 任务完成的验证标准是什么。

在角色、创建参数和边界明确前，我只会等待澄清，不会自行切换为主智能体视角。
```
