## API 变更示例

```md
任务目标：调整某个 NeoDev API 的请求字段
命中的代码域：src/service、docker/
是否涉及外部环境：否

当前最可信的三个来源：
1. `src/service/routers/*.py`
   - 原因：定义当前对外 API 路径与入参入口
2. `src/service/services/*.py`
   - 原因：定义业务处理逻辑与字段流转
3. `docker-compose.yml` 与 `.env.example`
   - 原因：用于核对运行时依赖与环境边界

当前最小证据集：
- 已加载：router、service、根配置文件
- 暂不加载：无关模块、远端环境上下文
- 触发扩展加载的条件：如果数据库、容器或远端部署受影响，再读环境规则
```
