# 契约变更清单示例

本示例用于帮助执行 `cross-layer-contract-change-rule.md`，不替代正式规则。

## 适用场景

- 字段删除
- 字段改名
- 请求/响应结构调整
- DTO / VO / 数据库列同步收口

## 简化示例

```md
任务：删除旧字段 `legacyField`，仅保留 `currentField`

契约基准：
- 网关 `DescribeSomething.json`
- 页面通过统一 SDK 调用

本次差异：
- 删除：`legacyField`
- 保留：`currentField`

跨层影响面：
- 前端表单与类型：删除 `legacyField`
- 网关 JSON：删除请求/响应中的 `legacyField`
- 后端 DTO / VO / Mapper：删除 `legacyField`
- 数据库：若旧列仍存在，补迁移或删除脚本
- 验证：搜索仓库确认无残留引用
```
