# Examples Index

本目录用于放置规则、提示词和协作模板示例。

## 快速定位

- 我要看多智能体分派示例：
  - 看 `subagent-delegation-examples.md`
  - 其中也包含创建参数示例
- 我要看契约字段删除 / 改名的检查清单：
  - 看 `contract-change-checklist-example.md`
- 我要看“先列最小证据集再扩展阅读”的模板：
  - 看 `evidence-loading-example.md`
- 我要看规则写法示例：
  - 看 `rule-example.md`
- 我要看提示词示例：
  - 看 `prompt-example.md`
- 我要看提交示例：
  - 看 `commit-examples.md`

## 使用原则

- 示例用于帮助理解规则，不替代规则本身
- 需要正式约束时，仍应回到对应 `rules/` 或 `system/` 文件
