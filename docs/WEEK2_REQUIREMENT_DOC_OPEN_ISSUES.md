## 1. 已知环境阻塞

## 1.1 前端 `vite/esbuild spawn EPERM`

### 现状
- 该问题已被 Week2 明确保留为环境阻塞项。
- 它影响的是前端 `vite` / `esbuild` 驱动的 test/build 稳定性判断。
- 本次复核中 `npm run build` 已通过，未现场复现 EPERM；但 Week2 交付口径仍不能把该风险直接视为已关闭。

### 为什么要继续保留
- 这是执行环境层问题，具备偶发性和环境依赖性。
- 如果现在把它从结果包中删除，等于对评审造成“前端验证已经完全稳定”的误导。
- Week2 更需要诚实的风险边界，而不是漂亮汇报。

### 当前处理原则
- 继续记录为环境风险，而非主链功能缺陷。
- Week3 需要单独做环境复现、归因和关闭标准。
