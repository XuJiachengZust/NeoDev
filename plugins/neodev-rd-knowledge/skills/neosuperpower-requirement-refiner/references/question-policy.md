# 提问策略

## 1. 必须提问或进入待确认的问题

以下信息不得由 AI 自行决定：

- 业务对象标准名称、别名归属、对象定义、对象关系、生命周期。
- 属性含义、枚举值、状态含义、字段是否必填、校验规则、展示口径。
- 功能范围、非目标、权限边界、数据可见性、删除/恢复/撤销规则。
- 接口路径、请求响应结构、数据库结构、跨系统同步、异步处理、定时任务。
- 验收标准、异常处理、兼容策略、迁移策略、性能和安全指标。

## 2. 提问格式

每个问题应包含：

- 问题编号。
- 当前已知事实。
- 需要确认的选项或开放问题。
- 不确认会影响哪些 PRD 章节。
- 阻塞级别：阻塞/非阻塞。

## 3. 默认处理

- 阻塞问题：先向用户提问，不能继续写成确定需求。
- 非阻塞问题：写入 `99-open-questions.md`，并在相关章节标注“待确认”。
- AI 推断：只能写成“候选口径”，不得写成“当前确定规则”。

## 4. 典型阻塞问题

- 同一概念存在多个名称，且会影响对象、字段或接口命名。
- 删除、禁用、启用、编辑等操作的状态影响不明确。
- 权限或数据范围不明确，可能影响可见性或安全。
- 子功能是否纳入本期范围不明确。
- 验收标准无法从现有资料推导。
