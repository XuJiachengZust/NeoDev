# 测试方案模板

仅在“测试方案阶段”加载本文件。

用途：产出测试方案初稿，供用户在检查节点 1 确认。

## 必填章节

```markdown
# 测试方案

## 1. 测试目标
- 本轮测试要验证什么
- 本轮测试不验证什么

## 2. 测试范围
- 涉及页面
- 涉及资源类型
- 涉及规则或业务链路

## 3. 不在范围内
- 明确列出本轮不覆盖的页面、资源类型、异常路径或边界场景

## 4. 测试环境
- 环境名称
- 服务地址
- 浏览器执行方式

## 5. 测试账号
- 账号标识
- 账号权限说明

## 6. 测试数据准备
- 数据来源
- 数据批次
- 命中样本
- 对照样本

## 7. 测试矩阵
- 资源类型
- 场景
- 页面验证点
- 网络验证点
- 数据库验证点

## 8. 用例清单
- 用例编号
- 用例标题
- 覆盖目标

## 9. 证据规范
- 截图规则
- 网络规则
- 数据库证据规则

## 10. 判定标准
- 通过标准
- 失败标准
- 阻塞标准

## 11. 产物目录约定
- 产物根目录，必须位于产品根目录下的新建文件夹，默认 `<product-root>/acceptance-artifacts/<feature>-<yyyymmdd>/`
- 文档路径
- 截图路径
- 网络路径
- SQL 路径
- 日志路径
```

## 设计规则

- 测试范围和不在范围内必须同时存在
- 测试矩阵必须覆盖命中样本和对照样本
- 页面验证点、网络验证点、数据库验证点都必须落到具体对象
- 判定标准不能写成“看情况”或“基本正常”
- 产物目录不能放在 `harness/`、`docs/` 或具体子项目目录，除非用户明确指定其他产品根目录下的位置
- 方案初稿完成后必须停下，进入用户检查节点 1
