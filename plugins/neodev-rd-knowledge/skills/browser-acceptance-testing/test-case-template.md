# 测试用例模板

仅在“测试用例阶段”加载本文件。

用途：在测试方案确认后，产出详细测试用例，供用户在检查节点 2 确认。

## 用例必填字段

每个测试用例必须包含以下字段，不得缺项：

- `用例编号`
- `用例标题`
- `测试目标`
- `用户视角场景`
- `覆盖资源类型`
- `前置条件`
- `测试数据`
- `页面验证点`
- `网络验证点`
- `数据库验证点`
- `通过条件`
- `失败判定`
- `风险与边界`
- `产物路径`

## 用例设计规则

- 一个用例只验证一类主结论
- 每个资源类型至少包含命中样本和对照样本
- 每个页面验证点必须能映射到页面具体区域、列、标签区或提示信息
- 每个网络验证点必须能映射到具体请求
- 每个数据库验证点必须能映射到具体表、字段或查询结果
- 每个步骤都必须可截图、可判定
- 失败判定必须是显式条件
- 风险与边界必须写清哪些异常本用例不负责覆盖

## 单步设计硬规则

- 一个步骤只验证一个主断言
- 页面结论、网络结论、数据库结论需要拆分记录
- 同一步骤不能混写多个主结论
- 步骤必须能单独截图、单独记录网络、单独判定通过或失败
