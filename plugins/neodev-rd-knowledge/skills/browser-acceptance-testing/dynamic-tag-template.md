# 动态标签场景模板

仅在场景命中“规则配置 -> 执行任务 -> 页面可见 -> 数据库落库”链路时加载本文件。

本文件不是通用测试方案、通用测试用例或通用测试报告模板的替代品，而是场景补充模板。

使用顺序：

1. 先完成测试方案阶段
2. 再完成测试用例阶段
3. 仅在确认属于动态标签场景后，补充读取本文件

## 场景必填输入

- 标签名称
- 资源类型
- 规则定义
- 命中样本
- 对照样本
- 资源页面路由
- 页面可见性验证点
- 数据库表与字段
- 测试产物根目录

## 动态标签场景补充目标

动态标签用例必须额外覆盖以下主结论：

1. 动态标签可以成功保存
2. 规则能够命中预期样本
3. 手动执行任务成功
4. 命中样本在资源页面能看到该标签
5. 对照样本在同一页面看不到该标签
6. 数据库中的 `labels` 状态与页面结果一致

## 动态标签场景补充验证点

### 页面验证点

必须明确到具体展示位置，例如：

- 列表页标签列出现标签名称
- 详情页标签区域出现标签名称
- 对照样本对应行或详情区不显示该标签

### 网络验证点

至少覆盖以下类型的关键请求：

- 保存规则请求
- 执行任务请求
- 查询任务日志请求
- 查询资源列表或资源详情请求

### 数据库验证点

必须明确到表、字段和判定关系，例如：

- 目标资源记录的 `labels` 字段包含该标签 ID
- 对照资源记录的 `labels` 字段不包含该标签 ID
- 任务记录表中存在本次执行记录且状态成功

## 动态标签标准步骤

下面这组步骤是动态标签场景的最小标准路径，执行时不能随意省略：

1. 打开动态标签配置页
2. 填写规则并保存
3. 手动执行任务
4. 查看任务日志
5. 验证命中样本页面可见
6. 验证对照样本页面不可见
7. 执行数据库校验

## 动态标签失败分类

动态标签测试失败时，必须先归类，再定位。

### A. 规则命中失败

现象：

- 规则试运行返回命中 0 条
- 任务日志显示命中 0 条资源

优先检查：

- 样本数据值是否正确
- 元数据过滤条件是否命中
- 规则字段、操作符和值是否配置错误

### B. 运行链路 / 绑定链路失败

现象：

- 规则试运行能命中资源
- 任务日志失败，或数据库标签没有落下去

优先检查：

- 任务队列与任务日志
- 资源标签同步逻辑
- 运行期 SQL 与标签字段映射

### C. 页面查询链路失败

现象：

- 任务日志成功
- 数据库标签已落库
- 资源页面查不到命中样本，或查询时报错

优先检查：

- 资源页面查询接口
- 页面对应的 mapper / service 分支
- 当前资源类型的标签展示映射

## 动态标签报告补充字段

动态标签用例写入测试报告时，每条用例至少补充以下字段：

- `资源类型`
- `规则摘要`
- `命中样本`
- `对照样本`
- `任务日志结论`
- `失败分类`
