# 多智能体分派话术模板

仅在需要创建、复用或调整子智能体分工时加载本文件。

用途：约束主智能体如何向执行器子智能体和评估器子智能体发出清晰、可验收、不可越界的分派指令。

## 使用原则

- 主智能体负责规划、分派、监督、验收和收口
- 执行器子智能体负责具体执行，不负责重新定义任务目标
- 评估器子智能体负责检查结果，不负责顺手修改文件
- 浏览器会话默认只能由单一智能体串行驱动
- 分派内容必须明确角色、目标、边界、禁止事项和验收标准

## 分派必填字段

每次分派至少包含以下内容：

- `当前角色`
- `任务目标`
- `上下文范围`
- `允许操作或允许修改边界`
- `禁止事项`
- `预期产出`
- `验证标准`

## 执行器子智能体模板

适用：

- 数据准备
- SQL 校验
- 日志检查
- 代码定位
- 报告局部整理

模板：

```text
角色确认：你是执行器子智能体。

任务目标：
<写清这次只需要完成什么，不扩展目标>

上下文范围：
<列出允许读取的文件、目录、报告、产物路径>

允许操作 / 修改边界：
<写清可以改哪些文件，或只允许只读检查>

禁止事项：
- 不要重新定义任务目标
- 不要扩展为新的主线任务
- 不要修改未授权文件
- 不要替主智能体做最终验收和收口

预期产出：
<写清要返回什么，例如 SQL 结果、日志摘要、代码定位、报告片段>

验证标准：
<写清什么样的结果算完成>
```

## 评估器子智能体模板

适用：

- 审阅测试方案
- 审阅测试用例
- 审阅测试报告
- 审阅证据完整性

模板：

```text
角色确认：你是评估器子智能体，只做只读审阅，不修改文件。

任务目标：
<写清本次要评估什么，例如方案是否完整、报告是否缺证据>

上下文范围：
<列出允许读取的文件、目录、报告、产物路径>

允许操作 / 修改边界：
- 允许读取和分析
- 不允许修改文件
- 不允许执行会写入状态的操作

禁止事项：
- 不要顺手修正文档
- 不要替执行器补做执行任务
- 不要越界扩展评估范围

预期产出：
<输出通过 / 不通过 / 有风险待修复，并列出问题或建议>

验证标准：
<写清结论必须引用哪些文件或证据>
```

## 浏览器执行分派模板

适用：

- 主智能体决定把浏览器执行交给单一执行器智能体

模板：

```text
角色确认：你是执行器子智能体，负责单一浏览器会话执行。

任务目标：
按已确认的测试方案和详细测试用例执行页面测试，并保存截图与关键网络证据。

上下文范围：
<列出测试方案、测试用例、产物目录、目标环境、目标页面>

允许操作 / 修改边界：
- 允许执行浏览器操作
- 允许写入测试产物目录
- 不允许修改业务代码
- 不允许绕过用户检查节点

禁止事项：
- 不要改动测试范围
- 不要自行增删用例
- 不要并行驱动多个浏览器会话
- 不要在未记录证据时直接给出通过结论

预期产出：
- 用例执行结果
- 每步截图
- 每步网络记录
- 失败时的初步定位信息

验证标准：
- 每一步都有截图
- 每一步都有网络记录
- 每个失败用例都能指向后续定位入口
```

## 推荐分派场景

推荐优先分派以下任务：

- 大批量测试数据准备
- SQL 校验
- 日志检查
- 代码定位
- 报告只读审阅

不推荐分派为多个并行子智能体的任务：

- 同一浏览器会话下的页面点击、输入、截图、网络抓取

## 主智能体检查清单

主智能体发出分派前，先自查：

- 是否明确了子智能体角色
- 是否给出了清晰任务目标
- 是否限定了上下文范围
- 是否限定了允许修改边界
- 是否写清了禁止事项
- 是否写清了预期产出
- 是否写清了验证标准
