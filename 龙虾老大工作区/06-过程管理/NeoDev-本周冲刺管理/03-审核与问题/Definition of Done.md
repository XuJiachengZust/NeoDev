# Definition of Done

一个任务只有满足以下条件，才可视为完成：

## 1. 目标完成
- 达到任务定义的最小可用结果
- 没有偏离任务目标

## 2. 范围受控
- 只修改与任务直接相关的内容
- 没有混入无关改动

## 3. 工程可接受
- 结构与命名基本符合现有项目风格
- 没有明显破坏现有主流程

## 4. 验证完成
- 已执行该任务要求的最小验证
- 若未完成全部验证，必须明确说明

## 5. 留痕完整
- 已更新任务状态
- 已记录关键产物与风险
- 已准备好进入审核

## 6. 提交要求
- 必须形成最小可用单元 git 提交
- 提交内容应可独立理解
