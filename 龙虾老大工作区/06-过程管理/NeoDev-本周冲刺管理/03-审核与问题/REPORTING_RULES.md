# REPORTING_RULES

以后所有对老大的状态汇报，必须绑定证据，不允许只说“正在推进”。

## 必须满足的规则

### 1. 汇报必须带证据
至少包含以下之一：
- 新文件路径
- git commit hash
- 任务状态变化
- 审核结论
- 阻塞说明
- 验证命令与结果

### 2. 没有证据，不允许使用以下表达作为有效汇报
- 我在继续
- 我在推进
- 已回到主线
- 正在做

### 3. 汇报优先使用以下结构
- 当前任务：
- 当前状态：
- 证据：
- 下一步：
- 是否需要老大审核：

### 4. 如果处于 executing 且无新证据
必须转为以下之一：
- blocked
- replan_required
- 明确新增心跳记录
