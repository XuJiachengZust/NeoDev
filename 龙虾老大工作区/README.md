# NeoDev 龙虾老大工作区

这份工作区已按“渐进式加载”重组，默认阅读顺序是：

1. `00-总览与加载顺序/`：先看总览、加载顺序、阅读地图
2. `01-用户心智与战略/`：先理解用户心智，再理解产品战略
3. `02-P0产品定义/`：从战略收口到 P0 的产品定义与规格基线
4. `03-P0执行与任务包/`：再进入排期、批次任务包、直接开发任务包
5. `04-实证与验证/`：看如何验证关键假设
6. `05-历史规划与阶段分析/`：回看更早期的分析与阶段规划
7. `06-过程管理/`：执行制度、冲刺管理、脚本与审查约束
8. `07-日报/`：日常过程沉淀

## 设计原则

- **用户心智文档主导产品规划**：产品规划材料不再与心智研究并列散落，而是按“心智 → 战略 → P0 定义 → 执行 → 验证”的链路组织。
- **最小可用单元**：优先通过移动、归类、补索引完成整理，不粗暴删稿。
- **保留历史**：草稿、迭代稿、阶段性报告都保留，方便追溯判断演化。
